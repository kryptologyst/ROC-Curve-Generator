# ROC Curve Generator

**ROC curves** with AUC scores for binary and multi-class classification.

## Overview

- Binary and multi-class ROC curves
- AUC score computation per class
- Interactive Plotly visualization
- **Streamlit dashboard**

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
# CLI: python -m src.main generate --dataset wine
pytest tests/ -v
```

## Docker

```bash
docker compose up --build
```
